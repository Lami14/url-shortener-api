# URL Shortener API

A simple **URL shortening service** built with **Node.js, Express, and MongoDB**.  
This API allows users to convert long URLs into shorter links that redirect to the original website.

The project demonstrates backend development concepts such as **REST API design, database modeling, and redirect handling**.

---

## Features

- Create shortened URLs from long links
- Redirect short URLs to the original link
- Track the number of clicks for each shortened URL
- Store URL data in MongoDB
- RESTful API structure
